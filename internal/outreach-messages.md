# Outreach-повідомлення за типом стейкхолдера

**Не на публічному сайті.** Чернетки лише для внутрішнього використання.

- Текст (tracked): цей файл
- Зручний HTML з кнопкою «Копіювати» (gitignored): `internal/outreach.html`
  Відкрити локально: `open internal/outreach.html` або
  `cd docs && python3 -m http.server` не підхопить його з Pages —
  краще просто відкрити файл у браузері з диска.

Короткі супровідні повідомлення — 3–5 речень, з посиланням на сайт
(о проєкті / кандидати / фонди / мапа). Для email / Telegram / LinkedIn,
не для формального листа.

**Лінк для вставки:** https://maxsemenchuk.github.io/hromada-strategy-collab/

Цифри на момент оновлення (2026-07-31): **77** громад зі стратегією (**68** з текстом Goals),
**1 469** у метаданих, matching **v7**, **2 278** пар; продукт = **кандидат договору МСС**
(тема · одна з 5 форм), стратегії — один із сигналів пошуку.

Цінності аудиторій (публічно, коротко) — на лендингу: `docs/index.html#stakeholders`.

**Pitch (DOBRE):** найважчий етап МСС — пошук партнера (30%), не шаблон договору;
форма угоди — наступний шар підказки після пари.

Як справи? Дякую за попередні консультації щодо Civic Tech Lab — ми продовжуємо

У рамках тієї ж теми виникла ідея дивитися не лише на інструменти участі, а й на

цифровізації — чи варто розвивати саме цей ракурс, і чи є ідеї / контакти
(можливо, у Мінрегіоні), з ким логічно говорити про доступність стратегій і

## 2. Мінрегіон / розвиток громад

**Тема:** Аналітичний шар над реєстром МСС — перша перевірка

Ми поєднали тексти стратегій із відкритим мережевим шаром зареєстрованих угод МСС (KSE PIN) і спробували системно підказувати кандидатів на нову співпрацю. Метод підтвердився на реальному туристичному кластері Чернігівщини і підняв операційну пару (спільний ЦНАП), коли додали географію — чистий текст її пропускав. Корисна деталь для методології: тематичні / проєктні збіги краще ловить текст стратегій, а типові операційні угоди — близькість і вже наявна мережа. Чи цікаво обговорити, чи такий шар міг би доповнити моніторинг реєстру?

Сайт проєкту → https://maxsemenchuk.github.io/hromada-strategy-collab/

## 3. Громада (адаптується під конкретну пару — приклад для Ужгород/Мукачево)

**Тема:** Спільна можливість для Ужгорода та Мукачева — знайдена аналізом ваших стратегій

Ми проаналізували відкриті стратегії розвитку українських громад і звернули увагу на конкретний збіг: Ужгородська і Мукачівська громади, за ~40 км одна від одної, обидві розвивають туристичний продукт окремо (Ужгород — DMO та інфоцентр, Мукачево — замкові маршрути та інфоцентр), і Мукачево вже прямо планує лікарню, що частково обслуговуватиме Ужгородський район. Виникає природне питання: чи не варто об'єднати туристичний маршрут і, можливо, спільну заявку на транскордонний грант?

Це початкова гіпотеза з аналізу відкритих даних, не готова пропозиція — хотіли б перевірити, чи резонує вона з вашими реальними планами. Короткий дзвінок?

## 4. Донорські програми та фонди (загальний шаблон: DOBRE, МФ «Відродження», EGAP, U-LEAD, GIZ, ПРООН…)

**Тема:** Де наступна інвестиція підсилить вже вкладене в портфель?

Ваша програма профінансувала розробку стратегій / роботу з громадами — частина з них вже в нашому пілоті (~77 стратегій, теги DonorsPrograms на ~174 громадах). Ми зіставили портфель із аналізом стратегій і мережею МСС:

1) кого з «ваших» громад варто звести для спільного наступного гранту (замість двох паралельних);
2) куди розширити портфель, щоб закрити «дірку» в мережі;
3) які громади зручні як опорні для обміну досвідом між грантоотримувачами.

Підхід підтвердився на реальній угоді МСС. Це демонстрація, не готовий дашборд на весь портфель — для повного зрізу потрібне ширше покриття саме «ваших» громад.

Чи цікаво пройти 1–2 програми на сторінці «Фонди» і звірити з вашим внутрішнім списком?

## 4a. Олена Саєнко (керівниця програми EGAP, Фонд Східна Європа)

**Контекст:** найтепліший недавній консультантський контакт (Civic Tech / e-DEM).
Не холодний пітч «дивіться ваш портфель на вкладці Фонди» — для EGAP там
порожньо по стратегіях.
**Факти по даних (не пхати всі цифри в лист):** тег EGAP ≈11 громад; **0** зі
структурованими цілями стратегії → `funds.html` для EGAP нічого змістовного не
покаже. Зате для цих же громад є шар **ресурсів** (11/11) і **DREAM-пріоритетів**
(≈9/11). Тому запит — порадитися + допомогти закрити діру в стратегіях / списку,
а не «оцініть наш EGAP-зріз».

**Тема:** Апдейт після ваших порад · пілот зі стратегіями (і де нам бракує даних)

Привіт, Олено!

Дякую за недавні консультації — вони дуже допомогли. Ми продовжуємо цю лінію
роботи з громадами.

З’явився дослідницький пілот: читаємо стратегії розвитку і підказуємо, з ким
громадам є сенс співпрацювати (МСС / спільні проєкти) — у т.ч. щоб донорські
програми бачили, де наступна підтримка підсилює вже вкладене, а не дублює
паралельні треки.

Коротко:  
https://maxsemenchuk.github.io/hromada-strategy-collab/

Окремо — шар без PDF стратегії: ресурси громади та пріоритети проєктів DREAM  
https://maxsemenchuk.github.io/hromada-strategy-collab/resources.html

Чесно звернуся з тим, де ми самі впираємось. Для громад, які в нас позначені
як EGAP, стратегій у пілоті майже немає — тож «портфельний» зріз саме під EGAP
поки не зібрати. Зате для них уже є структурні ресурси й DREAM-пріоритети.
Тому хотів би порадитися не «оцініть готовий дашборд», а:

1) чи взагалі такий напрям (стратегії + співпраця громад) здається вам корисним
   для EGAP / Фонду — які плюси й які ризики / хибні очікування;
2) чи варто нам у першу чергу добивати відкриті стратегії по ваших громадах
   (або звірити список громад EGAP — можливо, наше покриття тегом неповне);
3) з ким ще логічно це коротко обговорити у вас або серед партнерів.

15–20 хвилин, коли зручно — буду вдячний саме за вашу думку як людини, яка
вже консультувала нас по цій лінії.

Макс

## 5. Анатолій Ткачук (Інститут громадянського суспільства)

**Контекст:** консультація щодо пілоту пошуку партнерів для МСС за текстами стратегій.
Спочатку — співчуття (нещодавно помер син). Не тиснути з «дзвінком на цьому тижні»;
проєкт — лише якщо й коли буде доречно. Перед відправкою перевірити актуальність

**Тема:** Співчуття · і, якщо доречно, коротка консультація щодо пілоту МСС

Шановний пане Анатолію,

Нещодавно, на жаль, дізнався про Вашу важку втрату — смерть сина. Прийміть мої щирі
співчуття. Дуже шкода; скорблю разом із Вами.

Не хочу нав’язувати робочу розмову в такий час. Якщо й коли Вам буде доречно, був би
вдячний за коротку консультацію з Вашого досвіду децентралізації та міжмуніципального
співробітництва.

Ми зробили дослідницький пілот: читаємо затверджені стратегії розвитку громад і
підказуємо, з ким є сенс домовлятися про МСС — не лише через особисті знайомства.
Реєстр угод показує, хто вже домовився; стратегії — хто міг би, але ще не в реєстрі.

Ніжин–Батурин–Козелець і кандидатів на кшталт спільного водопостачання Галич–Дубівці.
Це не готовий сервіс — хочемо зрозуміти, чи такі підказки взагалі корисні практикам
