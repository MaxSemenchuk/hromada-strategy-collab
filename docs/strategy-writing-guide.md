# Як писати стратегію, зручну для МСС

Короткий чеклист для громад і методистів. Мета — щоб стратегія лишалась
корисною для розвитку громади **і** давала машиночитабельні сигнали для
пошуку партнерів (МСС).

## Ієрархія, яку варто тримати явно

1. **Стратегічні цілі** (3–5) — короткі назви, без абзаців ЦСР.
2. **Оперативні цілі** (`N.M`) — конкретніше: що саме змінюємо.
3. **Завдання / заходи** — з географією, інфраструктурою, індикаторами.

У відкритих PDF часто видно лише стратегічний рівень; оперативка «тоне» в
тексті. Якщо оперативні цілі пронумеровані як `1.1`, `1.2` — їх можна
витягнути й порівнювати між громадами точніше, ніж загальні гасла.

## Що додає цінності для міжмуніципальної співпраці

- **Назвіть сусідів і спільний об’єкт** (річка, полігон ТПВ, ЦНАП, маршрут,
  медзаклад), а не лише «розвиток співпраці».
- Окремий підрозділ **«Міжмуніципальна співпраця / МСС»**: діючі угоди +
  бажані.
- Відрізняйте **унікальне** (аеропорт, ГМК, бренд, прикордоння) від
  шаблонного («сприятливий інвестклімат»).
- У **викликах** пишіть дефіцити (кадри, вода, відходи) — це сигнал для
  complementary matching («хто може допомогти»).
- У **сильних сторонах** — потужності, якими можна ділитись із сусідами.

## Чого уникати

- Три довгі абзаци «цілей», скопійовані з ЦСР без локальної конкретики.
- Один і той самий консультантський шаблон слово-в-слово в кількох громадах
  (для матчингу це хибний «збіг стратегій»).
- Згадки донорів без прив’язки до проєкту / партнера.

## Як це використовує цей проєкт

| Сигнал у тексті | Трек на сайті |
|-----------------|---------------|
| Схожі оперативні / стратегічні цілі | «схожа стратегія» (thematic) |
| Сусіди + гео / мережа МСС | «зручний сусід» (operational) |
| Сила / DREAM однієї ↔ виклик іншої | «доповнення ресурсів» |
| Пряма мова про кооперацію / МСС | «явний запит МСС» |
