# Барометр цифрової демократії (e-dem.ua)

Рейтинг залученості громад в е-петиції та громадський бюджет, побудований з
**живого публічного API e-dem.ua** (OpenCity / EGAP — Фонд Східна Європа,
Мінцифра, SDC) — того самого майданчика, на якому KSE-Loc-Data-Hub у 2022
робив одноразовий скрейп для `edem-data.csv` (див.
[external-data-sources.md](external-data-sources.md#e-dem-dataset-detail)).
Тут дані актуальні на момент запуску, а не заморожені у вересні 2022.

## Команда

```bash
yarn edem-barometer   # → data/releases/edem-barometer.json (+ .manifest.json)
```

Тягне `external_api/petitions/statistics.json` і `external_api/budgets/statistics.json`
(без токена), мапить `KOATYY`/`KOATTU` (legacy КОАТУУ) на `katottg` через
KSE-адмінмап, кешує сирі відповіді в `data/cache/edem/` (не в git).

## Що саме міряємо

| Компонент | Джерело | Що показує |
|---|---|---|
| `petition_activity_score` | `Petitions` (усього подано) | наскільки часто громада взагалі використовує петиції |
| `petition_participation_score` | `OnlineVotes` (підписи) | наскільки жителі реально підписуються |
| `budget_activity_score` | `Projects` (подано проєктів) | наскільки живий конкурс громадського бюджету |
| `budget_scale_score` | `Budgets` (грн, виділено на конкурс) | масштаб фінансування |

Кожен компонент — процентильний ранг (0–100) **серед громад з ненульовим
значенням**; якщо громада відсутня на платформі або має 0 активності —
компонент = 0 (а не якийсь середній ранг через прив'язку до маси нулів).
`overall_score` = середнє чотирьох компонентів. Три рівні (`низький` /
`середній` / `високий`) — терціли розподілу серед підключених громад;
`не підключено` — окремий бакет для нульового `overall_score`.

### Абсолютні числа vs на душу населення

`overall_score` — **абсолютний**: велике місто виграє просто тому, що в
ньому більше людей, а не тому що воно активніше на людину. Для порівняння
без цього перекосу є другий шар:

| Поле | Формула |
|---|---|
| `petitions_per_10k_pop` | `petitions_total / population * 10000` |
| `budget_uah_per_capita` | `budget_amount_total_uah / population` |
| `overall_score_per_capita` | середнє процентильних рангів цих двох, **лише для громад з населенням ≥ 1500** |
| `tier_per_capita` | той самий терцильний поділ, окремий бакет `населення замале` для тих, кого виключено з рангу |

Поріг 1500 — щоб одна петиція в селищі на 500 людей не давала
нереалізований сплеск «10 петицій на 10 тис. населення». Нижче порогу
raw-поля (`petitions_per_10k_pop`, `budget_uah_per_capita`) все одно
рахуються і зберігаються в даних — просто не беруть участі в рейтингу.

На практиці абсолютний і подушний рейтинги суттєво розходяться: у топ-15 за
`overall_score_per_capita` потрапляють, поряд з тими самими великими
містами, і малі громади на кілька тисяч жителів (наприклад Привільненська
сільська ТГ, ~5,5 тис. осіб) — які в абсолютному топі не з'являються
взагалі, бо просто фізично не можуть подати стільки петицій, скільки
Вінниця.

`consultations`/`open_city` е-dem ендпоінти віддають лише загальну
статистику по платформі, без розбивки по громадах — тому в барометрі їх
немає (на відміну від старого KSE-скрейпу, де вони теж по суті були бінарним
"є/нема" без деталізації).

## Обмеження — читати перед використанням

1. **Це не панель, а знімок.** Кожен запуск відбиває стан на момент запуску;
   для тренду по часу треба зберігати послідовні знімки самостійно.
2. **`war_status_sept_2022` застарілий.** Це поле KSE, зафіксоване у вересні
   2022 — воно НЕ бачить окупацій після цієї дати. Приклад із самих даних:
   **Авдіївка** (окупована з лютого 2024) досі позначена `"not occupied, in
   the war zone"` і виглядає активною (petitions_total=20) лише тому, що
   портал заморожений на довоєнному стані, а не тому що громада зараз щось
   публікує. **Сєвєродонецьк**, навпаки, коректно позначений `occupied` —
   бо він впав ще до вересня 2022. Перш ніж вважати активний скор доказом
   реальної активності прифронтової/окупованої громади — перевіряйте вручну.
3. **`не підключено` ≠ «немає е-демократії».** Це означає лише «немає на
   e-dem.ua» — деякі великі міста (Київ, Львів) мають власні,
   поза-платформні петиційні/бюджетні системи і в цьому барометрі виглядають
   як нульові.
4. **Довгий хвіст містить символічні записи.** Кілька громад мають портал з
   формальним бюджетом в 1 грн і 0 проєктів — технічно «підключені», але
   без реальної активності. Вони отримують `tier: низький`, а не
   `не підключено`, і це коректно відбиває їхню наявність на платформі, але
   не варто читати сам факт підключення як ознаку залученості.
5. **Метчинг КОАТУУ неповний (~90–95%).** e-dem іноді віддає КОАТУУ без
   провідного нуля (виправлено паддінгом) або нетиповий код; невелика
   частка рядків (переважно районні/обласні ради) відкидається свідомо.

## Порівняння з KSE `edem-data.csv`

| | KSE (2022) | Цей барометр |
|---|---|---|
| Дата | вересень 2022, статична | на момент запуску |
| Покриття (petitions) | 331/1469 | 479/1424 |
| Інструменти | 4 бінарні (petitions/consultations/budget/open_hromada) | 2 кількісні + масштаб (petitions, participatory budget) |
| Деталізація | 0/1 на інструмент | суми, голоси, грн, ранг 0–100 |
| Consultations/open_hromada | є (бінарно) | немає (e-dem віддає лише загальну статистику) |

Обидва джерела корисні для різного: KSE — ширший набір із 4 інструментів,
цей барометр — свіжіші й кількісні дані по 2 з них. Не змішувати без
позначки джерела.
